# Falcha.ca — Audit + Redesign Plan
Date: 2026-03-02

## 1) Quick Audit (Current Site)

### Strengths
- Brand story and culture are visible.
- Clear "Order Now" exists.
- Contact/location information is present.

### Problems to fix first (high impact)
1. **Homepage is too long and unfocused**
   - Users must scroll too much before key actions.
2. **Primary CTA flow is weak**
   - Order/Reserve/Call are not consistently repeated in strategic spots.
3. **Information hierarchy is unclear**
   - Sections feel equal importance; user intent (order, menu, visit) not prioritized.
4. **Mobile usability can be improved**
   - Dense text blocks and content-heavy sections reduce conversion.
5. **Trust conversion blocks are limited**
   - Reviews, ratings, social proof, and featured dishes are not framed as decision triggers.
6. **Menu discovery friction**
   - Menu flow should offer fast category jump + best-seller highlights.
7. **Local SEO opportunity missed**
   - Location-intent content can be stronger (Scarborough + Newari/Nepali query pages).

### Medium priority
- Copy polishing (some grammar/typo cleanup).
- Stronger visual consistency for headings/buttons/cards.
- Better footer with quick actions and hours.

---

## 2) New Homepage Structure (Conversion-first)

1. **Hero (Above the fold)**
   - Headline + 3 CTAs: Order Now / View Menu / Call
   - Trust chips: rating, reviews, location, open-now

2. **Top Dishes (Best sellers)**
   - 6 clickable menu cards with photo + price + "Add to Order"

3. **Menu by Category (fast jump)**
   - Starters / Main / Set Menu / Drinks / Desserts

4. **Why Falcha**
   - Authentic Newari flavors, fresh ingredients, family-friendly experience

5. **Social Proof**
   - Review snippets + Google rating + Instagram feed preview

6. **Visit & Contact**
   - Map, address, open hours, one-tap call/directions

7. **Sticky Mobile CTA Bar**
   - Order | Call | Directions

## 3) Demo Scope (What to show owner)

### Demo goal
A clean, modern landing page that immediately improves:
- Online orders
- Calls
- In-store visits

### Demo components
- New hero section
- Best-seller cards
- Menu preview section
- Location/contact section
- Mobile sticky CTA

### Menu section included
- "Quick Menu Preview" with categories + sample items.
- Final prices/items can be synced from owner's official menu.
